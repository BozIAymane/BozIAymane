# Assets

This directory contains static visual assets for the GitHub Profile README.

| File | Description |
|------|-------------|
| `header.png` | Custom header banner created with github-profile-header-generator style (dark constellation theme, neon `< / >` badges, name and title) |
| `groot.gif` | High-quality transparent animated Baby Groot waving "hi" |
| `footer.png` | Matching footer banner with subtle constellation mesh and closing tagline |
| `header.svg` | Legacy SVG header |
| `footer.svg` | Legacy SVG footer |

These files are referenced by `../README.md` using relative paths.
